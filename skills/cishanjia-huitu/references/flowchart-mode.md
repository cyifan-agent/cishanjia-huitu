# Scientific flowcharts and technical roadmaps

Use authored rounded rectangles/header contours, native gradients, explicit
connectors and live text. Preserve the source's wording, values, grouping,
wrapping, arrow routes, widths and hierarchy. Do not add inferred biological
anatomy or scientific corrections to a visual recreation.

Measure each panel and text line. Maintain one owner per box with its labels;
separate captions and arrows remain separate. A joined bus may own its connected
trunk/branches/heads, while visually crossing independent arrows stay separate.
Reconstruct continuous panel/background fills beneath every movable owner.
Use the source-connectors.md route schema and review every isolated/hidden/moved
connector, including enlarged junctions and all branch endpoints.

For several references sharing a style, prepare one reusable construction helper
for complete rounded boxes, top-rounded headers, text lines and routed arrows.
Instantiate unique owner/part IDs and symbol definitions; remeasure differing
dimensions and labels. Reuse style definitions and exact diagnostic caches, not
previous appearance approvals. The biological source-features-v1 contract applies
when actual biological owners occur; do not invent anatomy for text boxes.

Inspect source details and run glyph checks before native construction. Preview
loading supports installed Chinese .ttc families and variable .ttf weights.
Keep equivalent labels in one typography group. Split superscripts/styled runs
only where the source calls for it, using available glyphs and measured baselines.
Never drop a thin one-pixel superscript stem during diagnostic measurement.

Prepare and inspect the full master first. `review_prepare.py` can prepare the
evidence together but leaves every visual check unreviewed. For mixed-script
native spacing differences, supply source-measured, revision-bound text fitting
from detail-refinement.md, rather than guessing a universal spacing value.

Capture the intended native document before drawing. Complete whole-object
playback, movement/ungroup tests and actual export in the requested order.
Tell the user when later figures were partly prepared during earlier diagnosis;
playback duration alone is not total drawing time. Do not compare cached fixture
timings with a first figure's full preparation and repair time.
